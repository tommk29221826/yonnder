# 暇つぶし読書仕分けアプリ

青空文庫の作品をランダムに1件ずつ表示し、「読んだ」「読んでない」で仕分けて保存できるWebアプリです。
作者からも探せる「作者ガチャ」、印象的な一文から作品に出会える「一文ガチャ」機能付き。スマホ対応レイアウト。

## スクリーンショット

```
┌─────────────────────────────────┐
│   暇つぶし読書仕分けアプリ       │
│  青空文庫の作品をランダムに…     │
│                                 │
│  ┌───────────────────────────┐  │
│  │  羅生門                   │  │
│  │  著者：芥川龍之介          │  │
│  └───────────────────────────┘  │
│                                 │
│  [作品ガチャ]   [作者ガチャ]     │
│       [一文ガチャ]               │
│  [読んだ]       [読んでない]     │
│       [青空文庫で読む]           │
└─────────────────────────────────┘
```

## 機能

- **作品ガチャ**: 青空文庫の作品をランダム表示
- **作者ガチャ**: 作者をランダムに1人表示し、その作品一覧を表示
  - 作品一覧は最初10件まで表示、「もっと見る」で追加表示
  - URL がある作品には「青空文庫で読む」リンクを表示
- **一文ガチャ**: 名著の印象的な一文をランダムに表示
  - 最初は作品名・著者名を隠し、一文だけを大きく表示
  - 「答えを見る」ボタンで作品名・著者名を逆引き
  - 答えを表示した後に「青空文庫で読む」が使用可能（URLがある場合）
  - `quote` フィールドがある作品のみ対象（現在 6 件）
  - 対象件数は起動時に `console.log` で確認可能
- 「読んだ」「読んでない」で仕分けて localStorage に保存（一文ガチャ表示中も使用可能）
- 「青空文庫で読む」ボタンで作品ページを新しいタブで開く
- 同じ作品の連続表示を防止
- 重複保存を防止（読んだ ↔ 読んでない の付け替えも自動対応）
- ページ再読み込み後も保存内容が維持される
- スマホ対応レイアウト（横スクロールなし・ボタン押しやすいサイズ）

## 一文ガチャについて

`script.js` 内の `QUOTE_BOOKS` 配列に `quote` フィールド付きで作品を定義しています。
現在登録されている一文：

| 作品名 | 著者 | 一文 |
|--------|------|------|
| 人間失格 | 太宰 治 | 恥の多い生涯を送って来ました。 |
| 吾輩は猫である | 夏目 漱石 | 吾輩は猫である。名前はまだ無い。 |
| 走れメロス | 太宰 治 | メロスは激怒した。 |
| 羅生門 | 芥川 龍之介 | ある日の暮方のことである。 |
| こころ | 夏目 漱石 | 私はその人を常に先生と呼んでいた。 |
| 舞姫 | 森 鴎外 | 石炭をば早や積み果てつ。 |

`quote` のない作品は一文ガチャの対象外で、作品ガチャ・作者ガチャには引き続き登場します。

将来的には青空文庫本文から一文を自動抽出して `QUOTE_BOOKS` を拡充することも可能です。

## ローカルでの確認方法

HTMLファイルをそのままブラウザで開くと、`file://` プロトコルで動作します。

```bash
# 方法1: ファイルを直接開く（最も手軽）
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux

# 方法2: Python の簡易サーバーを使う（推奨）
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く

# 方法3: Node.js の http-server を使う
npx http-server -p 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pages で公開する方法

1. このリポジトリを GitHub にプッシュ
2. リポジトリの「Settings」→「Pages」を開く
3. 「Source」を `Deploy from a branch` に設定
4. ブランチを `main`（または `master`）、フォルダを `/ (root)` に設定して「Save」
5. しばらく待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## データ取得方法の説明

### 現在の実装

起動時に青空文庫の公式ZIPファイル（`list_person_all_extended_utf8.zip`）をフェッチしてCSVをパースします。
フェッチに失敗した場合は `script.js` 内の `SAMPLE_BOOKS` にフォールバックします。

一文ガチャは外部通信不要で、`QUOTE_BOOKS`（固定データ）から選びます。

### 作者ガチャの仕組み

`loadBooks()` 完了後に `buildAuthorMap()` を呼び出し、全作品を `author` でグループ化した `authorMap` を構築します。
作者ガチャは `authorList`（作者名の配列）からランダムに1名を選び、その作者の作品一覧を表示します。

### 一文ガチャの仕組み

`QUOTE_BOOKS` 配列には `quote` フィールドを持つ作品のみを定義します。
一文ガチャはこの配列からランダムに1件を選び、最初は一文だけを表示します。
「答えを見る」ボタンで作品名・著者名を表示し、URLがあれば「青空文庫で読む」が有効になります。

## localStorage の仕様

| キー | 内容 |
|------|------|
| `hima_read_books` | 「読んだ」作品の配列（JSON） |
| `hima_unread_books` | 「読んでない」作品の配列（JSON） |

保存データの形式：
```json
[
  { "title": "羅生門", "author": "芥川龍之介", "url": "https://www.aozora.gr.jp/cards/000879/files/127_15260.html" },
  { "title": "走れメロス", "author": "太宰治", "url": "https://www.aozora.gr.jp/cards/000035/files/1567_14913.html" }
]
```
