# 暇つぶし読書仕分けアプリ

青空文庫の作品をランダムに1件ずつ表示し、「読んだ」「読んでない」で仕分けて保存できるWebアプリです。
作者からも探せる「作者ガチャ」機能付き。スマホ対応レイアウト。

## スクリーンショット

```
┌─────────────────────────────────┐
│   暇つぶし読書仕分けアプリ       │
│  青空文庫の作品をランダムに…     │
│                                 │
│  ┌───────────────────────────┐  │
│  │  羅生門                   │  │
│  │  著者：芥川龍之介          │  │
│  └───────────────────────────┘  │
│                                 │
│  [作品ガチャ]   [作者ガチャ]     │
│  [読んだ]       [読んでない]     │
│       [青空文庫で読む]           │
│                                 │
│  ┌─ 作者ガチャ結果 ────────────┐ │
│  │ 夏目 漱石 (作品数: 5件)    │ │
│  │ 1. 吾輩は猫である [読む]   │ │
│  │ 2. こころ [読む]           │ │
│  │ ...            [もっと見る]│ │
│  └────────────────────────────┘ │
│                                 │
│  読んだ: 3件    読んでない: 5件  │
└─────────────────────────────────┘
```

## 機能

- **作品ガチャ**: 青空文庫の作品をランダム表示
- **作者ガチャ**: 作者をランダムに1人表示し、その作品一覧を表示
  - 作品一覧は最初10件まで表示、「もっと見る」で追加表示
  - URL がある作品には「青空文庫で読む」リンクを表示
- 「読んだ」「読んでない」で仕分けて localStorage に保存
- 「青空文庫で読む」ボタンで作品ページを新しいタブで開く
- 同じ作品の連続表示を防止
- 重複保存を防止（読んだ ↔ 読んでない の付け替えも自動対応）
- ページ再読み込み後も保存内容が維持される
- スマホ対応レイアウト（横スクロールなし・ボタン押しやすいサイズ）

## ローカルでの確認方法

HTMLファイルをそのままブラウザで開くと、`file://` プロトコルで動作します。

```bash
# 方法1: ファイルを直接開く（最も手軽）
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux

# 方法2: Python の簡易サーバーを使う（推奨）
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く

# 方法3: Node.js の http-server を使う
npx http-server -p 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pages で公開する方法

1. このリポジトリを GitHub にプッシュ
2. リポジトリの「Settings」→「Pages」を開く
3. 「Source」を `Deploy from a branch` に設定
4. ブランチを `main`（または `master`）、フォルダを `/ (root)` に設定して「Save」
5. しばらく待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## データ取得方法の説明

### 現在の実装

起動時に青空文庫の公式ZIPファイル（`list_person_all_extended_utf8.zip`）をフェッチしてCSVをパースします。
フェッチに失敗した場合は `script.js` 内の `SAMPLE_BOOKS` にフォールバックします。

### 作者ガチャの仕組み

`loadBooks()` 完了後に `buildAuthorMap()` を呼び出し、全作品を `author` でグループ化した `authorMap` を構築します。
作者ガチャは `authorList`（作者名の配列）からランダムに1名を選び、その作者の作品一覧を表示します。

## localStorage の仕様

| キー | 内容 |
|------|------|
| `hima_read_books` | 「読んだ」作品の配列（JSON） |
| `hima_unread_books` | 「読んでない」作品の配列（JSON） |

保存データの形式：
```json
[
  { "title": "羅生門", "author": "芥川龍之介", "url": "https://www.aozora.gr.jp/cards/000879/files/127_15260.html" },
  { "title": "走れメロス", "author": "太宰治", "url": "https://www.aozora.gr.jp/cards/000035/files/1567_14913.html" }
]
```
